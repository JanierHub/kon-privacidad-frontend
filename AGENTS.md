# IMPORTANT: Expo version requirements

This project must stay on **Expo SDK 54** (`expo ~54.0.0`).

Reason: the user's phone runs **Expo Go 54.0.8**, which only supports
SDK 54 projects. Do NOT upgrade to SDK 57 or any newer SDK, or the app
will stop opening in Expo Go on the user's device.

Current core versions (do not bump):
- expo: ~54.0.0 (installed 54.0.37)
- react-native: 0.81.5
- react: 19.1.0
- @expo/vector-icons: ^15.0.3 (installed 15.1.1)

Read the versioned docs at https://docs.expo.dev/versions/v54.0.0/
before writing any code.
